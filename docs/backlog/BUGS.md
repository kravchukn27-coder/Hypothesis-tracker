## BUG-012 — Ссылка на эксперимент в строке Backlog ведёт на 404

- **Status:** TODO
- **Priority:** High
- **Area:** Backlog
- **Type:** Bug
- **Summary:** Подпись «N эксперимент(ов) · Стадия» под названием гипотезы в таблице Backlog — это ссылка на `/experiments?hypothesisId=...`, а список `/experiments` удалён (PROD-031), поэтому клик даёт 404. Заодно убрать счётчик «1» — у гипотезы теперь максимум один эксперимент (PROD-034).
- **Description:**
  Репортнуто пользователем со скриншотом. Строка в `src/app/backlog/page.tsx` (~строки 248-258) рендерит `<Link href={`/experiments?hypothesisId=${h.id}`}>` — этот маршрут PROD-031 убрал вместе со списком `/experiments`, ссылка сейчас всегда 404. Похожая ссылка на `/backlog/[id]` уже была исправлена (ведёт на `/experiments/${experiment.id}` напрямую), но эта конкретная — в самой таблице Backlog — осталась нетронутой.

  Вместо перехода на карточку эксперимента пользователь хочет, чтобы клик вёл на Calendar и подсвечивал там эксперимент цветом — то же поведение, которое уже описано в UI-030 (полный таймлайн с выделением эксперимента по `experimentId`, вместо фильтрации до одной строки). Эту ссылку нужно завести на тот же `/calendar?experimentId=...` и то же выделение, когда UI-030 будет реализован (или сразу на новый механизм, если один фиксится вместе с другим).

  Отдельно: текст ссылки сейчас `"N эксперимент(ов) · Стадия"` со счётчиком (`activeExperiments.length`) — с PROD-034 у гипотезы не может быть больше одного эксперимента, так что число в начале подписи больше не несёт информации и его нужно убрать, оставив просто стадию (например «Discovery» без «1 эксперимент ·»).
- **Acceptance Criteria:**
  - Клик по подписи под названием гипотезы в Backlog не даёт 404 — ведёт на Calendar (`/calendar?experimentId=...`) с подсветкой эксперимента по принципу UI-030.
  - Подпись показывает только стадию эксперимента, без счётчика «N эксперимент(ов) ·» в начале.
  - Гипотезы без эксперимента и с архивным эксперимента продолжают показывать то, что показывают сейчас (просто без числа), поведение для этих случаев не меняется, кроме самого текста счётчика.
  - Не меняются доменная логика стадий, связь `Experiment.hypothesisId → Hypothesis` и остальная часть таблицы Backlog.

None else open. See `docs/VERSIONS.md` for closed items.
